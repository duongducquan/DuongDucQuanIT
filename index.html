Giới thiệu

Xin chào mọi người! Mình là Dương Đức Quân (DuongDucQuann), sinh năm 2006, đang theo học ngành Công nghệ Thông tin tại TP. Hồ Chí Minh.

Mình đam mê lập trình, phát triển phần mềm và các công nghệ mới. Mình không ngừng học hỏi, nâng cao kỹ năng và xây dựng các dự án thực tế để phát triển bản thân trong lĩnh vực Công nghệ Thông tin.

Lĩnh vực và kỹ năng

Lập trình Web Full Stack

  • Frontend: HTML, CSS, JavaScript, ReactJS.
  • Backend: Node.js, Express.js, PHP, CodeIgniter.
  • Xây dựng API RESTful, tích hợp cơ sở dữ liệu và xác thực JWT.
  • Phát triển website bán hàng, website giới thiệu và hệ thống quản lý.

Phát triển ứng dụng và hệ thống

  • Tìm hiểu quy trình phát triển phần mềm.
  • Xây dựng ứng dụng và tích hợp API.
  • Nghiên cứu AI, chatbot và tự động hóa.

Công nghệ bản đồ và API

  • Tìm hiểu OpenStreetMap (OSM).
  • Nghiên cứu Nominatim và Geocoding.
  • Tích hợp API bản đồ vào các dự án web.

Cơ sở dữ liệu và Backend

  • MySQL và thiết kế cơ sở dữ liệu.
  • Xây dựng API, xử lý dữ liệu và xác thực người dùng.
  • Tìm hiểu Docker, CI/CD và tối ưu hiệu suất hệ thống.

Thiết kế và công cụ văn phòng

  • Thiết kế giao diện website hiện đại, thân thiện.
  • Thiết kế PowerPoint chuyên nghiệp.
  • Xử lý dữ liệu, công thức và báo cáo bằng Excel.

Dịch vụ

Mình nhận hỗ trợ các dự án:

  • Thiết kế và lập trình website theo yêu cầu.
  • Phát triển giao diện Frontend và hệ thống Backend.
  • Xây dựng API và tích hợp cơ sở dữ liệu.
  • Thiết kế PowerPoint, xử lý dữ liệu Excel.
  • Hỗ trợ chỉnh sửa, tối ưu và hoàn thiện sản phẩm theo yêu cầu.

Mình luôn hướng đến sự rõ ràng, trách nhiệm, đúng tiến độ và chất lượng trong từng dự án.
